# Optional design-skill comparison

This is an experiment mode, not the default workflow. Three aesthetics with one chosen design approach are usually easier to judge than a large matrix.

For a comparison, hold the aesthetic fixed across treatments before judging treatments. A minimalist no-skill page versus a cinematic skill-assisted page confounds two variables.

Freeze the brief, reference screenshots, claims, assets, implementation scope, model/settings when controllable, and iteration allowance. Record exact skill names, versions or content hashes and prompts. Use explicit labels for any differences. If an asset is generated separately for each treatment, artwork becomes an additional variable.

Agree on matched guidance or full workflows. Matched guidance applies each skill's design advice under the same production steps. Full workflow runs may include different interviews, image stages or revision loops; describe them as workflow comparisons. Do not quietly present one as the other. User instructions take precedence over conflicting skill preferences.

The no-skill treatment means no extra design skill. For a cleaner baseline, use a fresh context for each treatment that has not read the other skills. A continuing conversation that already read skills is a continuing-context baseline. Do not claim it is uncontaminated or that one output proves a universally better skill.

Keep reference interpretation constant across treatments. Do not give one treatment actual screenshots and another only collection summaries. Do not hand the later treatments the earlier outputs unless shared iteration is the experiment.

Suggested prompt after inputs and scope have been frozen:

```text
Create [N] treatments within [AESTHETIC]: [TREATMENT LIST]. Use the same
brief, actual reference pack, shared assets, required content and build scope.
Use matched production steps and apply each treatment's design guidance.
Record deviations and context limitations. Keep each output separately
addressable and show a comparison at equal viewport sizes.
Do not declare a universal winner. Explain observable differences in
clarity, composition, reference interpretation, independence and usability.
```

For a video, show the matched input pack, one complete iteration, and concrete before/after details. Explain whether work shared a conversation. Avoid attributing every visible difference to the named skill: sampling, prompt differences, assets and revisions also affect the result.
